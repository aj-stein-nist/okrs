# BTF Secure Design through TLP

- What? Machine learning techniques for common security doc use cases.
- How now? Security docs created and manually reviewed by expensive experts.
- What's new? Apply techniques from EL in system safety analysis (TLP) to security.
- Who cares? All application security engineers with complex systems.
- How much? $45,000 ($35,000 for research, $10,000 for conferences)
- How long? 1 year
- Milestones? Threat model taxonomy; tool to flag risks; tool to compare threat models
